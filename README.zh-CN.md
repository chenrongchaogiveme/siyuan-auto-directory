# 自动目录

版本 `1.0.0` · 适用思源 `3.8.0+`

在当前文档上方显示真实子文档和正文引用文档目录。它只是一个阅读辅助浮层，不会修改正文，也不会出现在 Markdown/PDF 导出里。

## 关于这个插件

写这个插件，是因为我从 Obsidian 转到思源后，一直不太习惯思源的文档树管理方式。思源本身可以像 Notion 一样在创建文档时建立引用关系，但用 QuickAdd 快速创建文档时，新文档不会以引用形式渲染在文档页面里，也就不会自然形成目录树。

所以我按自己的使用习惯做了这个自动目录插件：点进一篇笔记时，尽量把当前笔记下的文档结构和笔记详情展示在正文上方，既能快速看清层级，也不用频繁切到左侧文档树。

另外，我基于 Obsidian 的 QuickAdd 思路做了思源版 [QuickAdd](https://github.com/chenrongchaogiveme/siyuan-quickadd)：可以按自己的需要配置动作指令，把新建笔记直接落到指定位置。自动目录负责把创建出来的文档结构展示清楚，两个插件搭配使用会更顺手。

## 快速开始

1. 在 `设置 -> 集市 -> 插件` 搜索“自动目录”并安装，或手动把插件目录放入 `{workspace}/data/plugins/siyuan-auto-directory`。
2. 启用“自动目录”。
3. 打开任意有子文档或正文引用的文档，目录会自动出现在正文上方。
4. 点击顶栏右侧的列表图标打开设置。

## 功能亮点

- 📁 **真实子文档树**：按思源文档树顺序显示子文档，支持展开/收起和直接子文档数量。
- 🔗 **正文引用目录**：引用精确挂在包含引用的那篇笔记下方，默认显示两条，点击 `+N` 展开其余引用。
- 🏷️ **被引用标记**：被其他目录笔记引用的节点只保留紧凑“被引用”标记。
- ⏱️ **时间信息**：目录行右侧显示最后修改时间；创建时间默认在标题悬停提示中，可在设置中常显。
- 🧭 **面包屑返回**：点进子文档后，顶部提供“返回上级”和可点击面包屑。
- 🖱️ **拖拽排序/移动**：拖到行上缘/下缘调整同级顺序，拖到行中间移入目标子文档。
- ✅ **批量删除**：顶部“全选” + 每行复选框，选中后“删除选中”。
- ⚡ **大目录优化**：每层先渲染 120 项，超出后“加载更多”。
- 🔄 **自动刷新**：子文档新增、删除、重命名、移动或引用变化后自动更新。
- 🧹 **旧目录清理**：检测旧版插件生成的目录块，先隐藏，可在面板中确认清理。

## 常用操作

| 操作              | 效果                 |
| ----------------- | -------------------- |
| 点击目录标题      | 打开对应文档         |
| 点击展开箭头      | 展开/收起子文档      |
| 点击 `+N`         | 展开该笔记的其余引用 |
| 拖到行上缘/下缘   | 同级上移/下移        |
| 拖到行中间        | 移动为目标子文档     |
| 勾选行 + 删除选中 | 批量移入回收站       |
| 顶栏列表图标      | 打开插件设置         |

移动前默认会确认；首次确认框可勾选“不再提示”，之后也能在设置里重新开启。

## 设置项

顶栏右侧的列表图标打开设置：

- **最大目录层级**：`0` 表示不限制
- **默认展开层级**：仅在开启“默认展开目录”时生效
- **默认展开目录**：关闭后首次显示全部收起，适合文档很多或层级很深的情况
- **显示子文档数量**：在每个可展开目录项右侧显示直接子文档数
- **显示最后修改时间**：在目录行右侧显示文档最后修改时间
- **显示创建时间**：关闭时仍可在标题悬停提示中查看；开启后显示在标题下方
- **显示正文引用的文档**：关闭后只显示真实子文档
- **移动前确认**：拖拽移动时先确认；可在确认框中勾选“不再提示”，再从这里重新开启

## 为什么不是写进正文

思源的 HTML 块运行在 `protyle-html` 的 Shadow DOM 中，并经过 DOMPurify：

- 插件 CSS 无法进入 Shadow DOM，目录没有样式；
- 点击事件会被 `<protyle-html>` 截获，展开和打开按钮失效；
- 写入块还会让旧目录与新目录重复。

因此插件渲染在 `.protyle-content` 的普通 DOM 浮层中，视觉上位于当前文档上方，但不会修改正文、不会导出到 Markdown/PDF。

## 安装

### 从集市安装

打开 `设置 -> 集市 -> 插件`，搜索“自动目录”或 “Auto Directory” 安装。

### 手动安装

把整个目录放到思源的插件目录，例如：

`C:\MyDocument\SiYuan\data\plugins\siyuan-auto-directory`

然后在思源中启用「自动目录」。

## 已知限制

- 目录是阅读辅助浮层，不会导出到 Markdown / PDF，也不会写入正文。
- 引用优先从思源 `refs` 索引读取，能覆盖目录内各篇笔记；索引暂不可用时会退回当前编辑器 DOM。
- 如果同级位置与思源自定义排序冲突，排序会提示先调整文档树的排序规则，避免擅自清除用户排序。

## 开发

`index.js` 是构建产物，不是手写入口。源码按职责拆分：

- `src/api.js`：思源内核 API
- `src/tree.js`：文档树构建、引用合并、签名
- `src/renderer.js`：只渲染可见层级，引用按行内少量展开
- `src/panel.js`：浮层生命周期、展开、打开、删除
- `src/move-dialog.js`：移动确认与“不再提示”
- `src/selection.js`：选择状态
- `src/settings.js`：设置对话框
- `src/time.js`：思源时间格式转换
- `src/legacy.js`：旧目录块检测与清理
- `src/plugin.js`：插件生命周期
- `src/entry.js`：构建入口

```powershell
npm install
npm run build
npm test
npm run package
```

`npm run package` 会生成集市用的 `package.zip`。
